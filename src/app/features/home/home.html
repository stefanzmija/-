Твоите барања се само твои

Правилата за пристап се во самата база (Row Level Security). Студентот ги гледа само своите барања — дури и ако некој се обиде да ја заобиколи апликацијата. 

create policy "own tickets"
  on tickets for select
  using (
    created_by = auth.uid()
    or is_staff()
  );
